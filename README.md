# Motor Speed Prediction Using Machine Learning

## Overview

This project investigates machine-learning methods for estimating the speed of a Permanent Magnet Synchronous Motor (PMSM) from electrical and operating measurements.

The long-term objective is to investigate the feasibility of a machine-learning-based virtual speed sensor.

## Current Stage

Phase 1 — Dataset acquisition and data audit.
